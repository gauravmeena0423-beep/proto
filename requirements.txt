# Drishti SCRB Crime Intelligence Platform - Requirements

This is a pure Frontend Web Application. No backend server (like Node.js or Python) is required to run the core UI.

## System Requirements
- Modern Web Browser (Google Chrome 90+, Mozilla Firefox 88+, Safari 14+, Microsoft Edge 90+)
- Local Web Server (optional but recommended for fetching local assets without CORS issues). You can use any of the following:
  - VS Code Live Server extension
  - Python: `python -m http.server`
  - Node.js: `npx serve`

## External CDN Dependencies
The project relies on the following libraries loaded via CDN:
1. Leaflet.js (v1.9.4) - For Hotspot Mapping
2. D3.js (v7) - For Criminal Network Graph
3. Chart.js (latest) - For Dashboard and Trends forecasting
4. Web Speech API - Native browser API for voice recognition (No external library needed, but requires browser support)

## Development Requirements
To modify the codebase, you will need:
- Code Editor (e.g., VS Code, Sublime Text)
- Basic understanding of HTML5, CSS3 (variables/custom properties), and Vanilla JavaScript (ES6+)
